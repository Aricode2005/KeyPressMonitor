# Contributing

Thanks for your interest in KeyPressMonitor!

1. Fork the repo and create a branch (`git checkout -b feature/my-idea`).
2. Build with `build.bat` from an **x86 Native Tools Command Prompt for VS** and test by running `KeyMonitor.exe`.
3. Keep the style: comment each procedure, align operands, avoid dependencies beyond `kernel32.lib`.
4. Update the README if you add a feature or key binding.
5. Open a pull request describing what changed and why (screenshots welcome).
